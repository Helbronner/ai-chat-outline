# AI Chat Outline

AI Chat Outline is a Chrome extension that automatically generates an outline of your conversations. Currently, it only supports Google Gemini.

## How to install

1. Download the project by clicking the green **<> Code** button and selecting **Download ZIP**. Once the download is complete, unzip the file.

2. In Chrome, enter `chrome://extensions/` in the address bar to open the Extensions management page.

3. Enable **Developer mode** in the upper-right corner.

4. Click **Load unpacked** on the left side of the page.

5. Navigate to the downloaded project folder, select the `src` folder, and click **Select** to complete the installation.

## How to use

Open Google Gemini and click the extension icon. The chat outline will then appear in the right-hand sidebar.

For easier access, you can pin the extension to the Chrome toolbar.

> [!TIP]
> If the chat outline does not appear in the right-hand sidebar, try refreshing the current Gemini page.

## Privacy matters

Nowadays, people increasingly rely on artificial intelligence (AI), particularly large language models (LLMs), to accomplish tasks and spark creativity. However, the more you interact with these models, the more personal information you may expose.

As an independent third-party extension, AI Chat Outline operates separately from LLM providers such as Google, OpenAI, and Anthropic. **All processing takes place locally in your browser. No chat data is transmitted to external servers or stored by the extension.**

While we have not yet commissioned an independent organization to audit our data protection practices, we encourage users to review the source code themselves and raise any questions or concerns.

We plan to provide more detailed explanations of the extension's internal logic in a future update. Stay tuned!
